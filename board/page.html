Put a new model on the board

Any folder in the repo that holds a board_backtest.csv and/or board_forecast.csv shows up after a refresh. The easiest way to write them is one call at the end of your script:

from board.publish import publish

publish("test_models/myModel/out",
        predictions=preds,   # columns: model, target, year, state, actual, predicted
        forecast=fc_2026,    # columns: model, target, state, predicted[, lo80, hi80]   ("US" row allowed)
        cards={"ridge_weather": {
            "signals": ["weather", "NASS history"],      # from: satellite, weather, economy, NASS history
            "features": ["reversion", "d_drought", "rain_anom"],
            "description": "Ridge on last year's change plus drought and rain."}})

target is silage or grain. One folder can hold many models: one row per model name. If you already have per-year errors, pass backtest= with columns model, target, year, state_error_pct, us_error_pct instead of predictions=. A field-level classifier writes board_field.csv with model, evaluated_on, n_fields, silage_precision, silage_recall, silage_f1, accuracy.

The folders read today are listed in board/sources.py. Models still running are fine: the board reads whatever is on disk when you press Refresh.
