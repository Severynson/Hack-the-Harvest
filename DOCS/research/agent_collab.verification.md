## Corrected claim

**agent_collab-6:** CLAUDE.md rules are not enforced. A Claude Code PreToolUse hook on `Edit|Write` can block rewrites, but that matcher does not see Bash or script writes, and by default a hook that fails or times out lets the call through. Setting `"onFailure": "block"` on the command hook (Claude Code v2.1.295 or later) makes it fail closed. Git hooks and CI should still back it up. The local draft-hook test results were not independently verified.

## Missed by the researcher

1. `pull_request_target` workflows run even when the pull request has a merge conflict; it is stated in the same paragraph as the quoted sentence. It can carry the required append-only check in the concurrent-append case, but it runs base-branch code with a write token, so it must not check out or execute pull-request code. https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows
2. Claude Code hooks can be made fail-closed with `"onFailure": "block"` (v2.1.295 or later). The default command-hook timeout is 600 seconds, so a stalled hook also delays the call for up to ten minutes before it is let through. https://code.claude.com/docs/en/hooks.md
3. Read and Edit deny rules are not limited to the Edit and Write tools: they also apply to file commands Claude Code recognizes in Bash (`cat`, `head`, `tail`, `sed`, `tee`) and to redirection targets. Only unrecognized commands and arbitrary subprocesses escape, and the sandbox is the documented OS-level fix. https://code.claude.com/docs/en/permissions.md
4. Cursor's working answer was a planner and worker hierarchy, not better locking: planners create tasks, workers do them without coordinating with each other, and "Workers were already capable of handling conflicts themselves". The finding reports only the failures. https://cursor.com/blog/scaling-agents

## Overall

All eight sources exist and every quoted passage and number was found verbatim; seven findings hold as stated and one (agent_collab-6) needs a wording fix because hooks can be configured to fail closed. The GitHub union-driver finding rests on two agent-written pull requests and a 2017 support reply rather than GitHub documentation, so present it as observed behavior, and the handshake test should confirm it on this repository. The local hook and script test results in agent_collab-6 were not independently checked.
